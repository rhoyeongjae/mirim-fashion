# mirim-fashion

---

## 실행 가이드

### 1. 필수 라이브러리 설치

프로젝트 실행에 필요한 패키지를 설치합니다.

npm install

### 2. 환경 변수 설정 (.env)

프로젝트 루트 디렉터리에 `.env` 파일을 생성하고 필요한 환경 변수를 설정합니다.

> 실제 DB 접속 비밀번호와 NVIDIA API Key는 구글 클래스룸 비공개 댓글을 참고해 주세요.

### 3. 프로젝트 실행

**백엔드 서버 실행**
node src/app.js

**프론트엔드 실행**

`home.html` Live Server
